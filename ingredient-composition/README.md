# Ingredient Composition Chart

![Ingredient Composition](./fig/chart.png)

## Overview

A stacked 3D bar chart displaying the relative concentration of active ingredients per serving across all three Pludo flavors: Pink Yuzu, Watermelon, and Lemon.

## How to read this chart

- The vertical axis represents percentage of total active ingredient content per serving.
- Each color segment corresponds to one ingredient.
- All three flavors share a similar composition profile, with minor variations per flavor.
